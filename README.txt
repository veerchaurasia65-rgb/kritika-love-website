KRITIKA LOVE WEBSITE — UPDATED VERSION

Files:
- app.py: Flask website with interactive love-meter, Navratri greeting and reveal pages
- requirements.txt: dependency list
- static/kritika-background.jpg: original background photo
- static/kids-photo.png: supplied childhood photo used as the final reveal background
- static/devi-ji.jpg: supplied photo of Kritika used in the final reveal
- static/maa-durga.png: devotional Durga artwork for the Navratri reveal

Run locally:
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python app.py
5. Open http://127.0.0.1:5000 in your browser.

To publish it online, deploy this Flask app to a Python-compatible hosting service and include the static folder.
